앱으로 설치하기

학습·점검·챗봇을 홈 화면에서 빠르게 실행할 수 있습니다.

설치 가능 여부를 확인하는 중입니다.

Android

Chrome 또는 Samsung Internet에서 포털을 열고 메뉴의 앱 설치 또는 홈 화면에 추가를 선택합니다.

iPhone·iPad

Safari에서 포털을 연 뒤 공유 → 홈 화면에 추가를 선택합니다. iOS는 브라우저 설치 팝업이 없을 수 있습니다.

Windows·Mac

Chrome 또는 Edge 주소창의 설치 아이콘이나 메뉴에서 앱 설치를 선택합니다.

Android APK 테스트 설치

안드로이드 전용 앱 파일이 필요하면 GitHub APK 빌드 기록에서 성공한 실행의 Artifacts를 확인하거나 테스트 APK 릴리스를 확인하세요.

주의: 개발용 Debug APK는 기기 설치 허용이 필요하고, 기존 버전 위에 업데이트되지 않을 수 있습니다.

※ 개인정보 보호를 위해 입력한 질문·동의서·처리방침의 내용은 오프라인 캐시에 저장하지 않습니다. 인터넷 연결이 필요한 기능은 오프라인에서 사용할 수 없습니다.
