## 1. 주요 관리 범위

- 생성형 AI(ChatGPT 등) 업무 활용 보안: 비공개 정보·개인정보 입력 금지, 계정 보호 [「챗GPT 등 생성형 AI 활용 보안 가이드라인(2023.6)」(2023.06) p36, p58]
- 생성형 AI 개발·활용 시 개인정보 처리: 학습데이터 출처 검증·전처리·가명·익명처리, 입출력 필터링 [「생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서(2025.8.)」(2025.08) p14]
- AI 시스템 레드티밍: 탈옥·프롬프트 인젝션 등 적대적 점검과 출시 전 사전 검증 [「[최종]AI 보안 레드티밍 가이드」(2026.07) p11, p15]
- AI 에이전트(Agentic AI) 권한 통제: 최소 권한, 사용자 승인(Human-in-the-Loop), 감사로그 [「Agentic AI 위협」(발행연도 미표기) p6, p7]
- AI 보안 위협 대응: CEO·CISO부터 실무자까지 독자별 대응 절차 [「[최종]AI 보안 위협 대응 매뉴얼」(2026.07) p10]
