## 4. 초안 대비 검증 메모

- 초안의 '접속기록 월 1회 이상 점검'은 현행 「개인정보의 안전성 확보조치 기준」 제8조제2항과 다릅니다. 현행 기준은 점검 주기를 내부 관리계획으로 정해 이행하도록 합니다(「개인정보의 안전성 확보조치 기준 안내서(2026.11)」(2026.11) p22). 기관 내부 규정에 월 1회로 정해 두는 것은 가능하지만 법정 의무 주기로 안내하지 않습니다.
- 초안의 '분쟁조정 의무화'는 첨부 자료에서 근거를 확인하지 못해 뺐습니다.
- '2차 인증'은 원문 표현인 '안전한 인증수단(인증서·보안토큰·일회용 비밀번호 등)'으로 바꿨습니다(「개인정보의 안전성 확보조치 기준 안내서(2026.11)」(2026.11) p20).

이 문서는 첨부 자료에 근거한 일반 안내입니다. 자료와 현행 법령이 다르면 현행 법령(국가법령정보센터)을 따릅니다.
