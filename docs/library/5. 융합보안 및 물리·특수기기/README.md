- 고정형 영상정보처리기기(CCTV) 설치·운영: 안내판, 공공기관 의견수렴, 운영·관리 방침 [「★고정형 영상정보처리기기 설치 운영 안내서(2024.12)」(2024.12) p21, p27]
- IP카메라 보안: 초기 비밀번호 제거, 이중 인증, 펌웨어 업데이트, TLS·mTLS 통신 [「IP카메라_설치·운영_보안_가이드」(2025.11) p5, p7, p11]

- 위치정보 위반사례 [「위치정보사업자등 법규준수 실태점검 주요 위반사례집」(2026.03)]

## 4. 초안 대비 검증 메모

- 초안의 '커넥티드카(ISO/SAE 21434)'는 첨부 자료에 없어 뺐습니다.
- 초안의 '로봇 단말·제어 플랫폼 간 mTLS'는 로봇 자료에서 확인되지 않았습니다. mTLS는 IP카메라 가이드(「IP카메라_설치·운영_보안_가이드」(2025.11) p11)에만 나오므로 IP카메라 항목으로 옮겼습니다.
- 초안의 'OTA 무결성·전자서명 검증'은 이 카테고리 자료에서 확인되지 않았습니다. 패치 파일 무결성 검증은 기반시설 제어시스템 항목(카테고리 4, 「주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드」(2026) p469)에, 전자서명 확인은 시큐어코딩(카테고리 3, 「Javascript_시큐어코딩_가이드(2023년_개정본)」(2023) p94)에 반영했습니다.

이 문서는 첨부 자료에 근거한 일반 안내입니다. 자료와 현행 법령이 다르면 현행 법령(국가법령정보센터)을 따릅니다.
