# 요망진 간세다리와 함께 배우는 개인정보 보호

홈 화면은 **CTF 챌린지 보드**입니다. 안내 캐릭터 **간세다리**(제주 조랑말)와 함께 각 레슨을 미션으로 깨면 다음 단계가 열립니다(플래그 제출·점수·등급). 흐름도에서 움직이는 패킷은 달리는 간세다리로 표현됩니다.

개인정보의 **수집 · 이용 · 제공 · 파기 흐름**, **안전성 확보조치**, **개인정보 암호화**(비밀번호 일방향, AES·ARIA·SEED 대칭키, 전송 구간 TLS, 파일 암호 설정), **웹 취약점 구동원리**를 브라우저에서 직접 돌려 보며 배우는 정적 교육 사이트입니다.

- 서버, 빌드 도구, 외부 라이브러리 없이 HTML·CSS·JavaScript만으로 동작합니다.
- 모든 암호화와 공격 시연은 방문자의 브라우저 안에서만 실행됩니다. 입력값과 파일은 어디에도 전송되지 않습니다.
- 근거: 「개인정보 보호법」, 「개인정보의 안전성 확보조치 기준」(개인정보보호위원회 고시 제2026-9호, 2026. 7. 1.), 「개인정보의 안전성 확보조치 기준 안내서」(2026.11.), 「개인정보 영향평가 수행안내서」(2025.10.), 「개인정보 유출등 대응 안내서」(2026.9.)

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. 예: `privacy-lab` (Public)
2. 이 폴더의 내용을 **폴더 구조 그대로** 올립니다.
   - 웹에서: 저장소 화면 → **Add file → Upload files** → 압축을 푼 폴더 안의 파일·폴더를 모두 끌어다 놓기 → **Commit changes**
   - 터미널에서:
     ```bash
     git init && git add . && git commit -m "개인정보 보호 실험실"
     git branch -M main
     git remote add origin https://github.com/<아이디>/privacy-lab.git
     git push -u origin main
     ```
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 선택하고 **Save**
4. 1~2분 후 `https://<아이디>.github.io/privacy-lab/` 에서 열립니다.

> `.nojekyll` 파일은 GitHub Pages가 Jekyll 처리 없이 파일을 그대로 제공하도록 합니다. 지우지 마세요.

로컬에서 미리 보려면 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

## 암호 구현 검증

`ciphers.js`의 ARIA·SEED는 S-box를 정의식(GF(2⁸) 역원 거듭제곱 + 아핀변환)으로 생성합니다. RFC 5794(ARIA-128/192/256), RFC 4269(SEED) 테스트 벡터와 OpenSSL 3.0의 `aria-128-cbc`, `seed-cbc` 출력으로 바이트 단위 일치를 확인했습니다. push할 때마다 GitHub Actions(`.github/workflows/test.yml`)가 테스트를 다시 돌립니다.

**교육용 구현입니다.** 실제 서비스에는 검증필 암호모듈(KCMVP) 또는 검증된 라이브러리를 사용하세요.

## 내용 수정

- 레슨 설명 문구: `index.html`의 각 `<section class="lesson" id="...">`
- 흐름도 단계: 해당 `labs-*.js`의 `steps` 배열 (`title`, `html`, `fields`, `law`)
- 퀴즈: `labs-privacy.js`의 `Q` 배열 `[질문, [보기...], 정답 인덱스, 해설]`
- 새 레슨: `index.html`에 `<section class="lesson" id="새-id" hidden>` 추가 + 목차 `<a href="#새-id">` 추가 + `PI.onLesson('새-id', fn)` 등록
